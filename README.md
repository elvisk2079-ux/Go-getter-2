# Go Getter 2

Interactive vocabulary trainers for *Go Getter 2*: picture flashcards with Russian translations and audio, then many drills with instant checking — listening, translation, sentences, spelling.

Site: https://elvisk2079-ux.github.io/Go-getter-2/

- Places in a school
- A day at a boarding school — words from the reading text
- `src/` — sources and build scripts (`sh src/build_all.sh`)
